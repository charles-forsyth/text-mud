# Haunted Castle MUD

A single-player text-based adventure game set in a haunted castle.

## Goal
Find the **Golden Key** in the **Great Hall** and escape through the **Front Gate**.

## How to Run
```bash
python3 mud_game.py
```

## How to Play
-   **Move**: `n`, `s`, `e`, `w` (or `go north`, etc.)
-   **Look**: `look`
-   **Take Item**: `take [item name]`
-   **Check Inventory**: `i` or `inventory`
-   **Quit**: `quit` or `exit`

## Tests
Run the unit tests with:
```bash
python3 -m unittest tests/test_game.py
```
